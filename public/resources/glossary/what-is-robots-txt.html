What is robots.txt?

By Mushbloom · Published and updated 12 October 2026

Plain-text edition

Definition & overview

robots.txt is a file that gives compatible crawlers instructions about which paths they may crawl. It is not authentication and does not reliably hide private information or remove indexed URLs.

Analogy & mental model

It is a sign asking visitors where not to walk, not a locked door.

Protect private data with real access controls and manage indexing separately from crawl preferences.

Why robots.txt matters

Crawler instructions affect discoverability, but confusing them with security can expose sensitive information. A private page must be protected independently. Public pages also need a deliberate relationship between crawling preferences and indexing directives.

Practical business example

A site asks crawlers not to visit an admin area but still requires sign-in and role checks to access any private information.

Illustrative scenario, not a client case study or promised result.

How robots.txt works

  1. Place the file at the website root and define relevant crawler groups.
  2. Review allow and disallow rules for intended public and private paths.
  3. Test rule interpretation and actual server access, then manage indexing separately.

Core components & mechanisms

  • User-agent groups
  • Path rules
  • Optional sitemap reference

A disallowed URL can still be known to an engine through external links, and noncompliant clients can ignore the file.

robots.txt vs noindex

robots.txt controls compatible crawling. noindex requests exclusion from an index and normally must be fetched to be seen.
