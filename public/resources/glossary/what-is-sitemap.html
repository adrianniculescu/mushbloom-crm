What is XML sitemap?

Definition & overview

An XML sitemap lists preferred website URLs to help search engines discover pages. Submission is a discovery hint and does not guarantee crawling, indexing or ranking.

Analogy & mental model

It is a catalogue of books you would like the library to consider, not confirmation they are on the shelf.

List public canonical pages, keep the file current and inspect indexing in the relevant search tools.

Why XML sitemap matters

A sitemap provides a discoverable list of preferred public pages, especially when a site has many resources. It should represent the current site rather than every possible route. Search tools are still needed to establish which entries were actually crawled or indexed.

Practical business example

A glossary adds a new guide URL to its sitemap after publishing the substantive guide, excluding private administrative routes.

Illustrative scenario, not a client case study or promised result.

How XML sitemap works

  1. List valid public canonical URLs in the expected XML format.
  2. Publish the file and submit or reference it through suitable search tools.
  3. Review reported processing and page-level indexing rather than assuming success.

Core components & mechanisms

  • Canonical URL list
  • Valid XML
  • Discovery and inspection

Submission is a hint, not confirmation of indexing, ranking or AI source selection.

XML sitemap vs Internal link

A sitemap is a discovery list for crawlers. Internal links also provide reader navigation and contextual relationships between pages.
